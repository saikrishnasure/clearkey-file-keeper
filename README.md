# Clearkey File Keeper

create a website TrustVault is a secure document management and sharing platform designed to protect confidential documents through role-based authentication, document-level access control, and tamper-evident audit logging. The platform allows administrators, document owners, and viewers to perform authorized operations based on their roles and permissions. Document owners can upload, organize, search, update, and manage documents while granting or revoking read and edit permissions for specific users. The system enforces authorization on the server for every protected request, ensuring that unauthorized users cannot view, download, modify, or delete restricted documents. Permission revocation takes effect for subsequent access requests. TrustVault also maintains an audit trail of document uploads, downloads, modifications, deletions, permission changes, and denied access attempts. File validation, private storage, secure authentication, and automated security testing help protect documents against unauthorized access and common security threats. The administrative dashboard provides visibility into document activity and permission changes. The project aims to demonstrate how secure document sharing can be implemented using modern web technologies, with an emphasis on confidentiality, accountability, least-privilege access, and reliable security enforcement.
